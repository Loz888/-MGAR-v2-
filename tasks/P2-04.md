# P2-04 · DataAgent：只读 SQL 与数值证据

> **阶段：P2 — 真实 Agent Loop 与工具能力**  
> **依赖：P2-03**

## 本卡目标

Data Agent 根据观察生成受限 SQL 并迭代分析合成订单数据。

## 允许修改的主要文件/模块

`agentkit/mgar_agents/data/, fixtures/incident/sql/, tests/e2e/data_test.py`

如确需新增测试/小型辅助模块，可在本卡范围内增加；若涉及未批准的持久化协议修改或跨阶段大量重构，停止并提交 CHANGE_REQUEST。

## 开发步骤与设计要求

连接数据库只读账号；SQL 解析白名单和禁止 DDL/DML；只读事务+超时+limit；数值发现记录语句、参数、快照/版本、行数、输出摘要。

必须遵守 `02_ARCHITECTURE_CONTRACTS.md` 对身份、状态、预算和版本的约束；LLM 不能直接更新权威状态，所有新写路径均有真实测试和审计。

## 正向验收（必须自动化）

正常聚合/异常检测可复现 Ground Truth，结构化 Observation 引导下一轮分析。

## 反向验收 / 故障或越界（必须自动化）

SQL 注入/注释绕过/多个 statement/越权表/资源超限全部拒绝；不能仅靠正则保证只读。
