用真实 Provider 检验 Agent 决策与多 Agent 协作收益，严格隔离工程验证。

## 开发步骤与设计要求

要求显式 --confirm-live + MGAR_ALLOW_PAID=1 + MGAR_MAX_COST_USD + frozen caselist；配置单价版本、每个请求预留并入账；评测至少24条，优先 B0/B1/B2/B4，在授权不足时声明 NOT_RUN；保存请求/结果 hash、token、估算成本与独立 Oracle。

必须遵守 `02_ARCHITECTURE_CONTRACTS.md` 对身份、状态、预算和版本的约束；LLM 不能直接更新权威状态，所有新写路径均有真实测试和审计。
