## 本卡目标

可替换的 Mock 与至少一个真实 Provider，但默认离线。

## 允许修改的主要文件/模块

`agentkit/mgar_agents/provider/, agentkit/mgar_agents/core/errors.py, tests/unit/test_providers.py`

## 开发步骤与设计要求

实现 schema 校验、模型配置、响应解析、429/503/超时/网络中断分类；未知结果标记，不自动对可能已计费请求重播；真实 provider env/付费开关默认关。

必须遵守 `02_ARCHITECTURE_CONTRACTS.md` 对身份、状态、预算和版本的约束；LLM 不能直接更新权威状态，所有新写路径均有真实测试和审计。

## 正向验收（必须自动化）

Mock 完成 structured ToolCall/Result；受控 stub 模拟 429/503、错误 JSON、超时；账本事件正确分类。

## 反向验收 / 故障或越界（必须自动化）

未授权环境下真实请求 0 次；无限重试被预算挡住；不得存密钥或虚构 tokens=0。

```bash
python -m pytest -q tests/unit/test_providers.py
```

命令中的脚本/测试路径属于应交付接口；如仓库尚无该脚本，先在本卡实现所需脚本或等价测试入口并更新说明。Codex 必须记录真实运行的命令及退出码，不得仅复制上述命令假装执行。
