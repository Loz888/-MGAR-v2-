## 阶段门禁

1. 本阶段任务卡全部有真实 `accept.json`，0 FAIL / SKIP / XFAIL；未达成不进入下一阶段。
2. 完成 `scripts/test.sh --offline` 的相关回归；涉及 PG 事务时必须运行多进程 PG 集成测试；涉及安全时必须运行真实隔离负例。
3. 更新 `docs/limitations.md`，保留已知边界；证据摘要写入 `evidence/batches/P7/stage-summary.json`。
4. 不以 Mock 结果宣称真实 LLM 能力，不擅自进行付费调用。

**真实模型特别门禁**：`P7-06` 缺少用户付费授权可暂记 `NOT_RUN`，阶段结论只能是 `ENGINEERING_VERIFIED / LIVE_NOT_RUN`，不得标为 FULL。

**进入 P8 的例外**：仅 P7-06 在缺少用户付费授权时，可经用户确认以 `ENGINEERING_ONLY / LIVE_NOT_RUN` 前进。任何工程正反例 FAIL、SKIP、缺证据均不可使用此例外。
