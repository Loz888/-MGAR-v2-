# P2 · 真实 Agent Loop 与工具能力

> 阶段目标：三个异构 Agent 真正调用工具、观察结果并有限决策，不是多个脚本换标签

**执行规则**：按下列卡号顺序独立提交和验收，当前卡 PASS 后才进入下一卡。

| 顺序 | 卡号 | 交付目标 |
|---|---|---|
| 1 | [P2-01](../tasks/P2-01.md) | 实现通用 Agent 抽象、Turn 状态与 Tool Observation，不把 Agent 等同脚本。 |
| 2 | [P2-02](../tasks/P2-02.md) | 可替换的 Mock 与至少一个真实 Provider，但默认离线。 |
| 3 | [P2-03](../tasks/P2-03.md) | Research Agent 具备搜索、读取、引用、整合的真实工具循环。 |
| 4 | [P2-04](../tasks/P2-04.md) | Data Agent 根据观察生成受限 SQL 并迭代分析合成订单数据。 |
| 5 | [P2-05](../tasks/P2-05.md) | ActionAgent 根据上游证据提出修改并在临时环境验证，不在用户仓库直接写。 |

## 阶段门禁
