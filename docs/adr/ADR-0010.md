# ADR-0010：数据库审计投影与 OpenTelemetry 关联

状态：接受；范围 P6-04；不变更数据库权威协议或历史行。

固定 Go OpenTelemetry SDK/OTLP HTTP exporter 1.38.0 与 GenAI semantic conventions 1.37.0。Trace ID 使用既有 workflow_events.trace_id 的 run UUID 去连字符形式；Task/Agent 关联 ID 从 run、层级与实体 UUID 确定性派生。W3C traceparent 只用于观测关联，绝不作为身份或 DB 写权限；不传播 baggage、tracestate 或认证 Header。

读取同一 PostgreSQL repeatable-read 只读快照中的事件、Task、模型账本与交接收据，再导出明确标记 reconstructed 的审计 Span。Span 时间是已提交审计记录时间/投影窗口，不冒充未记录的模型内部时序；成功由权威事件判断，不能从 Span 有无推断。进程在提交后、导出前崩溃时，重启可重建这些已提交记录；未提交事件、未记录业务细节或原始实时 Span 无法恢复，必须标记缺失。重复投影使用稳定 ID，接收端是否去重取决于后端。

只导出 UUID、角色/状态枚举、修订/计划/epoch、计数、已知用量与成本；不读取原文 payload、goal、snapshot、工具参数或认证信息。任意模型名称只导出摘要；未知用量保持未知。默认不导出，显式本地 OTLP HTTP 只允许 loopback 字面 IP，固定无代理客户端、无 Header、禁止重定向，覆盖 SDK 环境配置。提供本地 collector 配置与真实 OTLP mock 接收器测试。

Python 提供兼容的 W3C 关联与闭集安全属性，不引入第二套权威审计或 Python DB 写路径。完整 Worker 自动接线属于 P7。
