# ADR-0020 · 独立修复后回归轮与累计预算

Status: APPROVED FOR PREPARATION — 用户要求修复开发集并安排新冻结实验；未自动执行。

旧轮永久保留STOPPED_UNKNOWN、34调用、1只读未知及83 NOT_RUN；不改账、不恢复，
不将旧轮失败覆盖为通过。新轮用同一24题×B0/B1/B2/B4复测修复后的通用契约，版本、
Run UUID、journal和PG分配标记独立，标为post_fix_regression。已有暴露题目，不声称
新未见holdout、无偏泛化或未测消融收益。公平地保持全96分母及同组预算/工具能力。

新轮approved cap=1900000微美元，96份各19791（合计1899936）；原轮上界33850
不释放，累计批准上界1933850小于2000000。前一轮结束report的hash与费用固定，
缺失或变化拒绝，不允许通过换DB/删journal/新选择器获得无限额。新轮仍需原paid flag、
精确项目USD2、冻结caselist、密钥、confirm。默认入口仍是旧轮；新轮仅显式--round round2。

对当前角色契约/网关源码与官方报价/evidence的hash冻结，任何修改须新版本/审阅；不以历史运行数据调答案。
元数据与独立分析记录round、prior上界和累计上界，不合并两轮样本。新轮支持与旧轮
相同的PG一用marker和fsync独占journal，未知停止全部后续项，不提供恢复或force开关。

本卡只完成配置、执行器/分析入口和只读预检；真实新轮明确NOT_RUN，后续可用已给出
的具体命令启动；不用准备就绪代替真实业务闭环。无新增DDL、无生产库写入。
