# ADR-0011：只读运维诊断与产物检查

状态：接受；范围 P6-05；不增加持久化协议。

CLI 的身份来自实际 PostgreSQL session/current role，不接受命令行自报管理员/Worker 身份。`mgar_reader` 是可信本地全局诊断角色；`mgar_worker` 无控制表读取权限。所有诊断先检查 DB 权限，再按 Run UUID 限定查询；不存在/跨 Run 产物使用统一错误，不返回数据库原始异常。CLI 不是多租户用户认证服务。

status/trace/budget-report 在单个 repeatable-read/read-only 事务中读取状态、计划历史、Task 及输入产物版本、账本和资源压力。仅提取必要结构化字段，任意 proposer/owner/capability 用摘要关联，排除目标、原文与认证数据。ReadAuditTx/BudgetReportTx 仅复用已有读取逻辑，不引入写权限；接管 epoch 与计划 proposer 的摘要可串联到同一操作者。

inspect-artifact 保留原接口 `ARTIFACT_ID`：经本地诊断 ACL 后定位其 run。可附加 `--run RUN_ID` 收窄范围，防止误查其他 run。读取私有 CAS 的实际有界字节并检查长度/SHA-256；默认只输出元数据与校验状态，不输出正文或执行内容。新增 CAS.OpenReadOnly 不创建目录且拒绝 Put。

doctor 只检查已配置环境、DB 身份、迁移校验和、CAS 可读性及本机工具可用性；不会调用 Migrate、清理数据库/容器/文件、修复账本或发送模型请求。错误必须输出机器可读 JSON 和非零退出码。cancel/resume 沿用既有状态机/未知副作用拒绝逻辑，不能由诊断自动触发。
