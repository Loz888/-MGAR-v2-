# ADR-0015 · 七组离线实验执行与共同评分

状态：已实施并验收；属于已批准 ADR-0014 方案 A 的 P7-03B，证据见 `evidence/batches/P7-03B/accept.json`。

实验配置冻结模型 demo-mock.v1、温度 0、工具 demo.v1、上下文上限和每题预算。
各题的预算取冻结 manifest；预算不足题不覆盖成默认上限。B0 使用一个真实 Worker
上下文和同等业务工具；B1 使用固定业务模板；B2/B3/A2 通过受预算约束的 Planner
生成、校验并执行业务 DAG，分别使用 full/selected/selected 输入。B4 与 A1
使用原严格 Runtime；只有 B4 接受已证实失败后的有界局部重规划。

隔离组的数据库 Plan 是身份/预算承载图，业务 DAG 另存于实际 Planner Artifact
和实验记录，由受信 Go 按依赖执行；不把全 root 承载图称为业务 DAG。B0 不进行
业务任务拆分。B3 和 A2 是相同处理的独立重复组，不能编造额外差异。

输入版本变化在第一次真实 SQL 读取后发生：先读取 prior_orders，再切到 orders。
固定基线保留旧候选并由共同 Oracle 判错；动态隔离组产生新承载 Plan 和候选，
不复用无验证的旧产物；B4 用正式 Replan 复用有效节点、重算受影响节点，A1
保留验证失败。所有先前调用、失败和版本均保留并计费。任务失败通过真实工具
调用的受控失败注入，乱序/重复通过真实 Handoff 投递注入；不只记录一个标签。

候选选择复用现有 Selector 算法，但输入仍为 unverified 候选信封；不得构造
可读取严格已验证输入的权限。当前小样本中关键证据可能全部保留，零收益照实报告。

共同外部 Oracle 在实验结束后读取冻结数学答案；incident 额外独立重执行实际
工作树测试，不能用 Agent 声称通过或内部 verdict 代替。外部检查不反馈给 Agent，
开销单列；所有组采用同一检查。只有数学评分和必要执行检查均通过才 oracle_pass。

每次独立 schema/CAS、真实预算和模型/工具账本。原始输出与 Trace 压缩保存，
JSONL 逐行追加、同步落盘；超时、解析错误、基础设施错误也占 assigned 分母。
Mock seed 固定决策/语义结果，不固定 UUID、进程号、并发顺序或实际耗时。
实验时延用单调时钟；严格 durable Workflow 终态时延另列，基线该指标 N/A。

不新增迁移、依赖或付费路径。原始数据与配置完整性验收属于本卡，统计推断和
消融解释属于 P7-04；Mock 结果仅支持工程声明。
