# ADR-0012：评测数据、语义 Oracle 与运行证据分离

状态：接受；范围 P7-01；不改变控制面协议或业务数据库。

冻结 mgar-dataset.v1：工程 60 条（十类各六），live holdout 24 条（简单/中等/困难各八，六个拒绝负例），开发 8 条。incident 调查并修复测试环境代码，analysis 仅做合成结算分析；两类共享明确整数金额语义，不能把 Mock 工程结论称为真实模型准确率。

Ground Truth 由独立纯 Python 数学脚本与人工回归样例构成，不导入 Agent、Tool 实现或内部 Verifier。现阶段 Oracle 判定语义，不以候选的 verified/passed 字段证明真实执行。P7-02 仍须组合真实控制面、授权工具、独立 SQL/沙箱重执行和来源校验；P7-01 的 PASS 不代表业务闭环已经运行。

Fixture 的 seed、旧/新输入、故障意图、预算与预期工程终态均冻结。task_failure/budget_exhausted 的安全失败是工程预期，语义任务本身仍可能未完成，后续统计必须保留失败分母。拒绝负例的正确拒绝与 Workflow succeeded 也要分开统计。

manifest 包含输入/真值/用例清单/Oracle 脚本/既有 incident 资产的 SHA-256，并由独立版本锁固定。validate 只读，不从运行结果更新答案；freeze 拒绝覆盖旧版本，修改数据或 Oracle 必须提升数据集版本并重跑各组。模型输出没有写入 Ground Truth 的接口；运行 Worker 的文件/API 隔离在 P7-02 接线时另验。

新库复现只创建随机 owned synthetic schema 和独立只读账号，参数化种子插入，清理仅限本次创建对象。live holdout 已冻结但绝不调用 Provider；缺少显式付费授权保持 NOT_RUN。
