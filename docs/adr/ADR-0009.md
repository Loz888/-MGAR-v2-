# ADR-0009：Ready 排序与授权成本路由

状态：接受；范围 P6-03；不增加表或改变状态机。

调度只读取当前计划及数据库 Ready 事件时间；从同一 run 已成功任务的执行/产出事件估计各角色耗时，缺样本用 1 秒，裁剪到 1 毫秒至 5 分钟。关键路径是剩余 DAG 最长耗时，Ready 等待时间按 1:1 累加，FIFO 使用 Ready 时间/节点名稳定排序。最长深度 6，因此关键路径最多 30 分钟；有限执行/有限资源且无未知占用时，aging 防止持续新任务饿死老任务。估计不作为正确性依据。

排序结果只携带当前计划版本与选中任务。领取沿用 workflow→budget→task→artifact 锁顺序，重新核验 Ready、计划版本、角色、依赖产物和预算；过时排序失败关闭，不退回任意任务。既有租约接管 API 保持独立。

Router 的配置来自可信主机，模型能力列表不授予工具权限。只允许已有离线 mock Provider；未授权/不可用/能力不足/超预算均明确拒绝，只有调用方显式开启 fallback 才从授权候选中选更低成本模型。路由解释绑定所选模型/价格，并随已有 model_reserved event 原子记录；最终额度仍由数据库预留判定，读取预算后存在竞争时不得发送。

固定负载实验实际执行有界本地计时工作、记录排队及完成时间；它是调度比较，不是模型质量、真实 LLM 时延或生产吞吐结论。
